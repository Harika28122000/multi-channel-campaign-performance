# Multi-Channel Campaign Performance & Budget Optimization

Real-world marketing analytics case study evaluating Paid Search, Paid Social, Email, Organic, Display, and Affiliate.

## Business problem
Decide where to increase, maintain, or reduce budget using CAC, ROAS, conversion rate, and traffic quality.

## Included
- Synthetic campaign data
- SQL KPI analysis
- Python analysis
- Dashboard-ready CSV

## KPIs
CTR, CVR, CAC, Revenue, ROAS, Spend, Conversions

## Data note
Synthetic portfolio data; no confidential employer data.
